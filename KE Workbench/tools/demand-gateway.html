Demand gateway

Turn under-served outcomes into demand requests that product and service owners can plan. Each request bundles desired outcomes, inherits the Outcome Playbook's Fix / Innovate / Protect / Simplify signal, and must pass the gateway's rules (traced, reviewed, evidenced, measurable, owned and unflagged) before it enters demand planning. Admitted requests are written back to the graph, so personas, jobs and the next study wave can see what is being done about each outcome.
