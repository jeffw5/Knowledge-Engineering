**Files here** (open `index.html` in the workbench to browse them as an outline)
- `apqc-pcf-7.4-category-3.txt`, `apqc-pcf-7.4-category-6.txt`: every element of categories 3.0 and 6.0, one per line, as `<hierarchy number> <name> (<element ID>)`.
- `crosswalk-7.2.1-to-7.4.csv`: what changed from 7.2.1, which the first Sales assembly used (added, removed, renumbered, renamed).

The registry built from these files is `KE Domains/Reference/apqc-pcf/` (APQC PCF Taxonomy 0.2.0, `https://www.insperity.com/taxonomy/apqc-pcf/`). That folder holds the master copy; this is the workbench's reference copy. To keep APQC's own file with it, download the PDF or Excel from the links above (APQC may ask you to sign in) and save it in both folders.
