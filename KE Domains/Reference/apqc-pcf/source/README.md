**Files here**
- `apqc-pcf-7.4-category-3.txt`, `apqc-pcf-7.4-category-6.txt`: the elements of categories 3.0 and 6.0, one per line, as `<hierarchy number> <name> (<element ID>)`, read from the 7.4 PDF. The registry builder reads the same files from `../../../_build/`.
- **Add the PDF and Excel here.** APQC's downloads need a free sign-in, so they could not be fetched from the build environment. Save `K014750 … PDF Version 7.4.pdf` (or the 8.0 files) in this folder to keep the source with the registry. With the 8.0 Excel here, the registry and the assemblies can move to 8.0 (open question 29).
