Appendix E • Section E.3 • Standards checklist

Standards Conformance

Checks vocabularies, taxonomies, ontologies and persona and jobs instance data against the standards of the guide in force: base URL and URI patterns, naming, acronyms, term definition fields, taxonomy rules, versioning, and the §3.13 jobs model (jobs broken into job steps, desired outcomes mapped to job steps and measured, personas that name their jobs) that §2.7 contextual relevancy maps every prompt to. Read straight from GraphDB, or load a Turtle file to check it before import.

Source
Reads only the predicates the checks need (type, labels, definition, parents, domain and range, scheme membership, versions, and the job, job step, outcome and persona links) from named graphs. Triples in the default graph are skipped — Model Manager's Set Named Graph moves them.
