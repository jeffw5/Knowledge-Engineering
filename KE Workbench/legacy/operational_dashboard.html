Run the agents

Runs every registered cartridge over whatever is checked in the Demand queue. Each artifact is routed by content, proposed on by its domain agent(s), passed through the deterministic validation gate, and — if it passes — committed to the KGCL log below.

Circuit breaker & drift monitor

Rejection rate is tracked per agent over its last 10 proposals. Crossing 40% trips that agent's breaker only — no other agent is paused. Value-drift is the same rolling rejection rate expressed as a coefficient.

Drag & drop agentic workflow orchestration

Drag pipeline-stage tiles and domain-agent tiles onto the canvas, then click one tile and then another to connect them (a line will appear). The five pipeline-stage tiles must all be present to run — they are the fixed governance sequence every artifact passes through. Which agent tiles you place controls which domains actually participate in this workflow run.
