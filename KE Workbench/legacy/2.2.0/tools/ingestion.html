Ingestion

Bring vocabularies, taxonomies and ontologies (Turtle, N-Triples or RDF/XML) into the standard. Each file gets new IRIs under the base URL, rebuilt metadata and a generated title and description where none is configured. Turtle and TriG copies go to separate folders, with a change record for the change log.

Reference ontologiesBFO 2020 (ISO/IEC 21838-2), the RO Core relations and the RO extract the core domain ontology imports: loaded as they are, under their own IRIs, never ingested
Defaults are the copies in KE Baseline/Baseline Core v1.0/reference/; a URL works too. Each replaces its own named graph: BFO in http://purl.obolibrary.org/obo/bfo.owl, RO Core in http://purl.obolibrary.org/obo/ro/core.owl, the RO extract in https://www.insperity.com/reference/ro-extract/. The workbench downloads the file itself and reads its format, so GraphDB needs no internet access.
